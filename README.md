# DevOps Cloud Deployment App

## 1. Project Overview

This project is a small Python Flask web application deployed using Docker and a cloud hosting platform.

The project demonstrates basic DevOps concepts such as containerization, environment configuration, version control, cloud deployment, port configuration, and reproducibility.

## 2. Technologies Used

- Python
- Flask
- Gunicorn
- Docker
- Git
- GitHub
- Render
